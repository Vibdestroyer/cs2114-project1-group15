
# CS 2114 Project 1 - Hokie Hustle

Hokie Hustle is a text-based Java game where the player must navigate
different encounters while trying to get to class before time runs out.

## How to Compile and Run

Ensure Java JDK 17 or later is installed.

Open a terminal in the project's root directory and run:

```bash
javac -d out src/Choice.java src/Encounter.java src/Person.java src/Friend.java src/Freshman.java src/Club.java src/Bus.java src/Restaurant.java src/User.java
java -cp out User
```

Run the project from root directory so the program can load the names correctly.
